# IT Services Website - Static Demo

A professional, modern, and sophisticated static website showcasing IT services with 3D interactive elements.

## Features

- 🎨 **Stunning 3D Visuals** - Interactive 3D scene powered by Three.js
- ⚡ **Blazing Fast** - Optimized Next.js with static generation
- 📱 **Mobile-First** - Fully responsive design
- 🎯 **Conversion-Focused** - Clear CTAs and professional presentation
- 🔒 **Secure** - Modern security practices implemented
- ♿ **Accessible** - WCAG compliant
- 🎭 **Professional Design** - Premium visual identity

## Technology Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Three.js / React Three Fiber
- Framer Motion
- Lucide Icons

## Getting Started

1. Clone the repository
2. Install dependencies:
   \`\`\`bash
   npm install
   \`\`\`
3. Run development server:
   \`\`\`bash
   npm run dev
   \`\`\`
4. Open [http://localhost:3000](http://localhost:3000)
